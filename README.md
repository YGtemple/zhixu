## 0. 先和大家打个招呼吧 👋

我是一名大二学生，平时课程和社团活动排得很满，总觉得自己在"记任务"这件事上花了不少时间，但任务还是越堆越多。之前用过不少待办 App，但它们大多只能帮我"记下来"，没法告诉我"今天先做哪个"或者"这句话到底是什么意思"。所以这次参赛，我想做一个能真正理解自然语言、还能帮我安排时间的工具。

初赛帖发布后收到了不少反馈，这两天我根据评委和社区同学的建议做了大幅升级——从 1.0 的基础待办+AI 解析，迭代到了 2.0 的**多视图时间管理 + 周期任务 + 子任务 + 场景模板 + 统计可视化**。整个 2.0 版本依然是一个纯前端单 HTML 文件，双击即用。

这个 Demo 是我和 TRAE 一起完成的。说实话，一开始我对前端开发并不熟，很多 CSS 动效和响应式布局的概念都是边做边学的。TRAE 最让我觉得"原来这么简单"的时刻，是当我跟它说"我想要一个玻璃拟态的侧边栏，带极光渐变"的时候，它直接给我生成了完整的 CSS 变量体系和 backdrop-filter 方案，我只需要调几个色值就能出效果。之前我以为这种视觉风格需要引入一堆第三方库，结果 TRAE 告诉我纯 CSS 就能搞定。

2.0 迭代过程中，TRAE 帮我实现了周视图时间轴网格、日视图精细时间线、周期任务自动展开、子任务进度追踪、5 类职业场景模板等复杂功能。特别是周视图的拖拽重排和时间块定位算法，涉及大量坐标计算和 HTML5 Drag & Drop 事件处理，TRAE 帮我一步步理清了逻辑，还在移动端做了横向滚动适配。

## 1. Demo 简介

**是什么：** 一个纯前端单 HTML 文件的 AI 增强型日程与智能待办助手，双击即可运行，无需安装、无需注册、无需后端。v2.0 在初赛基础上新增了 14 项功能升级。

**面向谁：** 学生、职场人、自由职业者、创业者、家庭管理者——任何需要管理日常任务但又不想被复杂工具绑架的人。2.0 新增了 5 类职业场景模板，首次打开即可一键载入对应角色的预设任务。

**v2.0 核心功能（14 项升级）：**

**视图层面**
- **周视图**：7 列时间轴网格，支持拖拽调整任务到不同日期和时段，上一周/下一周流畅切换
- **日视图**：单日精细时间线，可按日期选择器跳转，支持"添加到当天"快捷操作
- **月视图增强**：日历格 hover 显示任务详情浮窗，双击快速创建任务

**任务核心**
- **周期性任务**：支持每天/每周/每月/每年/自定义星期重复，完成后自动生成下一次
- **子任务**：每个任务支持多条子任务，带进度条可视化
- **每任务自定义提醒**：支持 5/15/30/60 分钟提前桌面通知
- **Markdown 备注**：支持链接、列表等简单 Markdown 语法

**AI 深化**
- **AI 智能编排**：结合预计时长+优先级+截止时间生成时间块（无 Key 时按优先级贪心分配）
- **自然语言编辑**：输入"把开会改到明天下午3点"直接修改已有任务
- **离线 NLP 扩展**：新增识别"大后天/月底/下周一/周X"等中文时间表达

**数据与导出**
- **CSV 导出**：一键导出为 CSV 表格，可用 Excel 打开
- **Markdown 导出**：导出为 Markdown 清单格式
- **JSON 备份 + ICS 日历**：原有功能保留

**场景模板**
- **5 类职业模板**：学生/职场/自由职业/家庭管理/创业者，首次打开或命令面板中一键切换

**交互优化**
- **统计折线图 tooltip**：hover 显示日期和完成数，点击查看当日明细
- **布局修复**：待办列表筛选标签不再与内容重叠，今日聚焦卡片窄屏自适应，看板列内容过多时正确滚动

## 2. Demo 创作思路

**灵感来源：** 我自己就是目标用户。每天打开待办 App，看到一堆任务但不知道从何下手，这种"记录了很多，但执行很乱"的感觉太熟悉了。我想做一个不只是"记"，还能"帮我想"的工具。

**v2.0 迭代思路：** 初赛发布后，我从不同角色的视角重新审视了产品：
- **学生**需要课程表式的周期任务和考试倒计时
- **程序员**需要多项目分类和每日站会记录
- **自由职业者**需要客户维度的工时追踪
- **宝妈**需要家庭成员标签和购物清单
- **创业者**需要 OKR 式目标层级和关键节点复盘

这些需求看似差异很大，但底层都是"任务+时间+分类"三个维度。我没有做 5 个独立产品，而是在同一个数据模型上通过**场景模板**来适配不同角色——首次打开选择一个模板，系统预填一组典型任务，用户在此基础上自定义。

**想解决的问题：**

- 手动填任务字段太繁琐，自然语言输入更直觉
- 任务多了之后，优先级和时间安排容易混乱
- 普通待办工具没有"执行"环节，记完就忘
- AI 工具好用，但接入门槛高，很多 Demo 没有 Key 就废了
- 不同职业角色对"任务管理"的需求差异大，通用工具往往两头不讨好

**为什么做这个方向：** 学习工作赛道强调"解决实际问题"。我觉得"时间管理"是一个足够小、足够具体的切口，但又能延伸出很多真实痛点。与其做一个大而全的协作平台，不如把"个人任务管理"这一件事做深，让评委和普通用户都能在短时间内感受到价值。

## 4. TRAE 实践过程

### 开发流程

整个 Demo 从 1.0 到 2.0 的开发大致分为以下几个阶段：

1. **需求梳理与 1.0 搭建**
   我先把自己的需求整理成一份产品描述，包括功能列表、视觉风格和交互逻辑，然后交给 TRAE 帮我转化为技术方案。1.0 版本完成了基础待办 CRUD、日历、看板拖拽、番茄钟、AI 解析和统计可视化。

2. **v2.0 需求收敛**
   初赛发布后，我从 6 个职业角色的视角收集了优化建议，整理出 P0（必做）到 P3（锦上添花）四个优先级。TRAE 帮我评估了每项功能在单文件约束下的可行性，最终确定了 14 项升级。

3. **UI 框架搭建**
   TRAE 帮我设计了一套"极光玻璃拟态"的视觉系统，包括 CSS 变量、渐变主题色、玻璃面板效果和响应式布局。2.0 中进一步优化了移动端适配，修复了筛选标签重叠、今日卡片截断、看板滚动等问题。

4. **核心功能迭代**
   周视图时间轴网格、日视图精细时间线、周期任务自动展开、子任务进度追踪、5 类职业场景模板等功能，都是我和 TRAE 一步步迭代出来的。特别是周视图的拖拽重排和时间块定位算法，涉及大量坐标计算和 HTML5 Drag & Drop 事件处理，TRAE 帮我一步步理清了逻辑。

5. **AI 能力接入与深化**
   TRAE 帮我实现了兼容 OpenAI Chat Completions 协议的 AI 调用模块，支持 SSE 流式输出、JSON 模式、本地额度管控和多供应商预设。2.0 新增了自然语言编辑任务、AI 智能编排结合预计时长的离线贪心算法。

6. **打磨与优化**
   最后阶段主要做细节优化：统计折线图 tooltip 交互、布局 bug 修复、命令面板新增周/日视图切换和 CSV/Markdown 导出命令、键盘快捷键扩展到 8 个视图。
