# zhixu

离线优先的日程助手——多视图、周期任务、自然语言录入。

<sub>单 HTML 文件 · 无后端 · 数据留在本地</sub>

---

## 做什么

一个页面搞定日常排程：

- **多视图**——日、周、月
- **周期任务**——每天、每周、按星期几、每月末
- **自然语言录入**——打「明天下午三点开会」，直接变成日程
- **离线可用**——数据全在 `localStorage`，完全断网也能用

## 为什么单文件、无后端

每天早上都要看一眼的助手，应该秒开，也不该因为服务器挂了就用不了。单 HTML 文件双击就能从磁盘打开。

代价是实打实的：不能跨设备同步，清掉浏览器数据日程就没了。JSON 导出就是为这个准备的。

## 三个值得说的设计决定

**重复任务算出来，不存起来。** 一条周期任务只保留一条规则，不是生成许多实例。月视图按需生成，所以一个日任务不会变成 365 行。

**自然语言本地解析。** 不调模型——一套小规则处理常见形态（相对日期、星期名、时间表达）。遇到复杂输入会直接说解析不了，而不是猜一个。

**月末重复单独处理。** 「31 号」在二月落到最后一天，不是跳过。这是周期任务代码最常写错的地方。
